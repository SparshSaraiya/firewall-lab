### 2c. Stateless 'fix' (pre-conntrack style): allow any server->client TCP packet that is not a SYN
$ ip netns exec fw iptables -A FORWARD -s 10.0.2.2 -p tcp ! --syn -j ACCEPT
$ ip netns exec client curl -sk --max-time 3 https://app.lab
Works. But the rule only looks at flags, not at who started the conversation. Test: SERVER sends unsolicited ACK probes; we sniff on the CLIENT side:
19:47:15.207281 IP 10.0.2.2.52720 > 10.0.1.10.4444: Flags [.], ack 4144110829, win 1024, length 0
19:47:16.208692 IP 10.0.2.2.52722 > 10.0.1.10.4444: Flags [.], ack 4143979759, win 1024, length 0
^ the unsolicited ACK crossed the firewall and reached the client (nmap shows 'filtered' only because the client's RST reply can't come back). A stateless rule lets anyone craft packets that look like replies.
